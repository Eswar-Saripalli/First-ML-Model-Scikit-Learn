# First ML Model with Scikit-learn

## Week 1 - SkillAudit.ai Machine Learning Internship

### Project Overview

This project demonstrates the basic machine learning workflow using the Iris dataset from Scikit-learn. Two classification algorithms were trained and compared based on their performance.

## Dataset

- Iris Dataset
- Total Samples: 150
- Features: 4
- Classes: 3

## Algorithms Used

- Logistic Regression
- Random Forest Classifier

## Evaluation Metrics

- Accuracy Score
- Classification Report
- Confusion Matrix

## Results

| Model | Accuracy |
|--------|----------|
| Logistic Regression | 100% |
| Random Forest | 100% |

## Tools & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Project Outcome

Both Logistic Regression and Random Forest achieved 100% accuracy on the Iris dataset. The project demonstrates data preprocessing, model training, evaluation, and comparison using Scikit-learn.
